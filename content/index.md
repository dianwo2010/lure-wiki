# 路亚百科

路亚百科是一个本地运行的中文路亚知识库，按十个分类整理路亚钓法的知识：从入门概念、线结和装备，到拟饵、鱼种、钓法，再到进阶技巧、实战经验，以及渔具品牌与水域环境。所有内容都是 Markdown 文件，可以在 Obsidian 中直接编辑，再由 Quartz 生成网站。

> [!tip] 本站处于搭建阶段
> 分类结构和知识范围已经定好，部分词条还在完善中。直接往对应文件夹里添加文章即可；文中带双链的词条，点进去就能继续补充。

## 知识分类

### 起步准备

- [[路亚入门/]] — 路亚是什么、基本概念与入门流程
- [[路亚线结/]] — FG 结等常用线结的绑法
- [[路亚装备/]] — 竿、轮、线的参数与搭配
- [[渔具品牌/]] — 主流品牌的系列划分与型号解读

### 认识对象

- [[路亚拟饵/]] — 米诺、软饵、金属饵的结构与适用场景
- [[路亚鱼种/]] — 鲈鱼、翘嘴等对象鱼的习性与钓法
- [[水域知识/]] — 水系分布、水流结构与标点判断

### 实战进阶

- [[路亚钓法/]] — 抛投、收线、抽停与水层搜索
- [[路亚技巧/]] — 找鱼、读水、控饵与中鱼技巧
- [[钓鱼经验/]] — 出钓记录、复盘与钓场笔记

## 如何使用本站

- **写文章**：用 Obsidian 打开 `D:\路亚百科`，在对应分类文件夹里新建 Markdown 文件，参照同目录已有文章的格式即可。
- **看网站**：双击 `D:\LureWiki\start-lurewiki.bat`，浏览器访问 `http://localhost:8080`。
- **更新文章**：保存 Markdown 后预览服务会自动重新构建；如果没开预览，重新运行启动脚本即可。
